# Support

Thanks for using HR Intelligence System. To help get a useful answer quickly, please choose the right channel.

## Where to ask

- **Bug reports:** use the GitHub bug report form and include minimal reproduction steps.
- **Feature ideas:** open a feature request; discuss larger changes before implementing them.
- **How-to questions:** first check the root README, the relevant component README, and [PANDUAN_PENGGUNAAN.md](./PANDUAN_PENGGUNAAN.md).
- **Security vulnerabilities:** follow [SECURITY.md](./SECURITY.md). Do not post exploit details publicly.
- **Contributing:** read [CONTRIBUTING.md](./CONTRIBUTING.md) and [CONTRIBUTE.md](./CONTRIBUTE.md).

## Include useful context

When asking for help, provide:
- affected component and version/commit;
- operating system and runtime versions;
- commands and sanitized error messages;
- steps to reproduce and expected behavior.

## Protect sensitive information

This project relates to HR systems. Never share real employee records, payroll details, personal information, credentials, access tokens, private keys, or confidential company data in public issues. Use synthetic examples and redact logs before posting.

## Production use

This repository is evolving. Validate functionality, access controls, security, privacy, model performance, and fairness for your own context before production use. Do not treat model outputs as the sole basis for consequential employment decisions.
