# Lisensi Dokumentasi

Dokumentasi, tutorial, panduan pengguna, diagram, dan materi penjelasan yang dibuat khusus untuk HR Intelligence System dilisensikan di bawah **Creative Commons Attribution 4.0 International (CC BY 4.0)**, kecuali jika suatu file menyatakan lisensi berbeda atau berisi materi pihak ketiga dengan ketentuan tersendiri.

Teks lisensi: [LICENSES/CC-BY-4.0.txt](./LICENSES/CC-BY-4.0.txt).

Kode sumber perangkat lunak mengikuti GNU AGPL-3.0-only. Potongan kode yang dimaksudkan sebagai bagian implementasi perangkat lunak tetap mengikuti AGPL kecuali dinyatakan lain. File model, bobot model, dataset, dependency, merek dagang, dan materi pihak ketiga tidak otomatis dicakup oleh lisensi dokumentasi ini.

CC BY 4.0 mensyaratkan atribusi ketika materi dibagikan. Pastikan proyek memiliki hak yang diperlukan sebelum menerapkan lisensi ini pada dokumentasi yang dibuat bersama atau berasal dari pihak lain.
