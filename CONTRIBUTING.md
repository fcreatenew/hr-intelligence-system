# Contributing to HR Intelligence System

Terima kasih sudah ingin berkontribusi! HR Intelligence System terbuka untuk pembelajar, mahasiswa, praktisi HR, software engineer, data scientist, ML engineer, dan profesional lainnya.

## Mulai di sini

Panduan kontribusi yang lebih lengkap tersedia di [CONTRIBUTE.md](./CONTRIBUTE.md). Panduan tersebut menjelaskan setup development, branch, testing, pull request, dan standar kontribusi.

## Alur singkat

1. Cari issue yang ada atau buat issue untuk mendiskusikan perubahan besar.
2. Fork repository dan buat branch khusus, misalnya docs/perbaiki-panduan atau fix/validasi-input.
3. Buat perubahan yang fokus dan tambahkan/perbarui test bila relevan.
4. Jalankan pemeriksaan yang sesuai dengan komponen yang diubah.
5. Buka Pull Request dengan ringkasan, alasan perubahan, cara pengujian, dan issue terkait.

## Kontribusi untuk semua tingkat pengalaman

Kontribusi tidak harus berupa fitur besar. Anda bisa membantu dengan dokumentasi, tutorial, reproduksi bug, test, aksesibilitas, UI, data sintetis, evaluasi model, keamanan, atau review kode.

Jika baru mulai, cari issue berlabel good first issue atau tanyakan di issue apakah suatu tugas cocok untuk pemula.

## Privasi dan keamanan

Jangan commit data karyawan nyata, informasi pribadi, credential, token, password, atau file .env. Gunakan data sintetis atau data yang jelas memiliki izin untuk digunakan dan didistribusikan.

Untuk laporan kerentanan, ikuti [SECURITY.md](./SECURITY.md), bukan membuat issue publik.

## Pull Request dan lisensi

Pada branch migrasi ini, target lisensi kode sumber adalah **GNU AGPL-3.0-only**; dokumentasi buatan proyek mengikuti **CC BY 4.0** sesuai [DOCUMENTATION_LICENSE.md](./DOCUMENTATION_LICENSE.md). Model AI, bobot, dataset, dan dependency pihak ketiga tetap mengikuti lisensi masing-masing.

Dengan mengirimkan kontribusi, Anda menyatakan bahwa Anda berhak mengirimkannya dan bahwa kontribusi tidak melanggar hak pihak ketiga. Kontribusi yang diterima akan didistribusikan berdasarkan lisensi yang berlaku pada bagian terkait. Kontributor tetap memegang hak cipta atas kontribusinya. Periksa file LICENSE dan cakupan lisensi sebelum mengirimkan PR.

Branch ini adalah rancangan migrasi. Jangan gabungkan sebelum checklist hak cipta dan kontribusi selesai ditinjau.
