# HR Intelligence System

Demo dan dokumentasi model Machine Learning untuk kebutuhan Human Resources:
prediksi **turnover**, **absensi tinggi**, **kategori kinerja**, **anomali
payroll**, dan **survival attrition**.

Space ini adalah halaman **statis** (tanpa kompute) yang menampilkan ringkasan
model dan menautkan ke server demo yang berjalan di tempat lain.

- **Model & metadata:** <https://huggingface.co/models> (repo model terpisah)
- **Dataset sintetis:** repo dataset terpisah
- **Source code:** GitHub (lihat bagian bawah halaman)

Semua model berjalan **CPU-only** (scikit-learn & lifelines), tidak
membutuhkan GPU. Seluruh data yang dipakai **anonim/sintetis**.
